# 角色池与启用规则

## 默认角色

- 软件架构师
- 测试工程师
- 资深用户
- 领域专家

## 按需角色

| 角色 | 触发条件 |
|---|---|
| 硬件/嵌入式专家 | MCU、驱动、传感器、功耗、PCB、接口 |
| DBA | 持久化、查询、统计、缓存、一致性、复杂数据模型 |
| UX/UI | 交互流程、界面、设备面板、易用性 |
| 产品/业务 | 目标模糊、MVP 未定义、优先级冲突 |
| 安全 | 账号、支付、隐私、远程控制、OTA、开放 API |
| DevOps/SRE | 部署、灰度、多环境、监控、回滚、日志 |
| 制造/供应链 | 量产、治具、替代料、生产测试 |
| 合规 | 监管、认证、审计留痕 |
| 算法/控制 | 滤波、补偿、PID/FOC、建模、复杂策略 |
| 交付经理 | 排期、多人协作、阶段验收 |
| 售后/运维支持 | 远程诊断、现场维护、支持闭环 |
| 成本角色 | BOM、云成本、授权、利润、预算 |

## 推荐启用模式

| 项目类型 | 默认角色 | 按需补充 |
|---|---|---|
| 纯软件 Web/App/中后台 | 软件、测试、资深用户 | UX、DBA、产品、安全、DevOps、成本 |
| 纯后端/平台/中间件 | 软件、测试、资深用户 | DBA、安全、DevOps、产品、成本 |
| 嵌入式/IoT/控制系统 | 硬件、软件、测试、资深用户 | 算法、DBA、安全、制造、合规 |
| SaaS/平台型 | 软件、测试、资深用户 | DBA、安全、DevOps、产品、成本 |
| 量产硬件 | 硬件、测试、资深用户 | 制造、合规、算法、软件、成本 |

## 强制补充规则

| 触发条件 | 必须补 |
|---|---|
| 账号、支付、隐私、远程控制 | 安全 |
| 云部署、上线运营、灰度、多环境 | DevOps/SRE |
| 量产、器件采购、治具、维修 | 制造/供应链 |
| 行业标准、认证、监管 | 合规 |
| 复杂控制、调参、建模 | 算法 |
| 明确排期和分阶段验收 | 交付经理 |
| 远程排障和售后闭环 | 售后/运维支持 |
| 明确预算和资源成本 | 成本角色 |

## 冲突裁决顺序

1. 安全 / 人身风险 / 合规红线
2. 核心业务正确性与可用性
3. 可测试性与可维护性
4. 交付可行性与稳定性
5. 成本与资源约束
6. 体验优化
